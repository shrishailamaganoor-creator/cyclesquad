# 🌍 Earth Heroes — Namma Bengaluru & Open-World Sustainability RPG

> **Earth Heroes** is an endless Pokémon FireRed-style open-world pixel-art sustainability RPG and waste-sorting arcade game built directly in HTML5 Canvas, Tailwind CSS, and Web Audio API.

🌐 **Live Demo:** [https://shrishailamaganoor-creator.github.io/cyclesquad/](https://shrishailamaganoor-creator.github.io/cyclesquad/)

---

## 🌟 Highlights & Features

- **🇮🇳 Namma Bengaluru (88×64) & 🏝️ Classic (48×36) Dual-Region Overworld:** Explore Vidhana Soudha, Cubbon Park, Lalbagh, MG Road, Indiranagar, Koramangala, Whitefield, and the Classic 4-Biome Isles.
- **🚲 Eco-Cycle Riding & Chiptune Bell:** Mount your Eco-Cycle (`B` / `Shift`) with tactile inertia physics and ring the chiptune bell (`E` / `🔔 BELL`) to clear commuters & students.
- **🚇 Namma Metro Viaduct Fast-Travel:** Hop on animated 3-coach Purple & Green Line trains across Bengaluru stations.
- **📋 7 Citizen Trust Missions:** Help 7 distinct Bengaluru citizens across `Lv.1 → Lv.3` scaling tiers with a golden directional compass arrow and 5-bin quick-sort carry bar (2x slots with the Bamboo Cargo Basket).
- **📹 Team Sludge Encounters → Eco-Cam & Sort Blitz:** Intercept patrolling Team Sludge Grunts and Lieutenants to launch the Eco-Cam viewfinder recording minigame followed by the 35-second Sort Blitz cleanup round.
- **📷 AI Field Lens (Gemini Vision):** Snap or upload real-world waste photos for instant AI classification and `$CYCLE` rewards.
- **🏪 Free-Cycle Bazaar & 🌍 World Guilds:** Unlock perks (`Bamboo Cargo Basket`, `Ranger Leaf Cap`, `Solar Micro-Grid Kit`, `Ocean Cleanup Net`, `Golden Sprout Companion`) and compete on the Guild leaderboard with an embedded Zero-Key Google Maps recycling drop-off finder.
- **📖 Field Manual / PDFs:** Open local PDF guides stored in `./docs/` directly from the top HUD.

## 🕹️ Controls

| Action | Desktop Keys | Mobile / Touch |
|---|---|---|
| **Move** | `Arrow Keys` or `W`, `A`, `S`, `D` | On-Screen D-Pad / Tap-to-Walk |
| **Eco-Cycle Mount/Dismount** | `B` or `Shift` | `🚲 CYCLE` Button |
| **Bell / Interact** | `E` / `Space` / `Enter` | `🔔 BELL` / `💬 ACT` |
| **Mission Board** | `M` | `📋 MISSIONS` |

## 🚀 Running Locally

No build tools, npm packages, or server runtimes required! Earth Heroes is 100% self-contained:

1. Clone the repository:
   ```bash
   git clone https://github.com/shrishailamaganoor-creator/cyclesquad.git
   ```
2. Open `index.html` directly in any modern web browser (Chrome, Edge, Firefox, Safari).
