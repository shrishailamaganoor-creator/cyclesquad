# 🚲 CycleSquad — Open-World Pixels Sustainability RPG

> **CycleSquad** is an endless Pokémon FireRed-style open-world pixel-art sustainability RPG and waste-sorting arcade game built directly in HTML5 Canvas, Tailwind CSS, and Web Audio API.

🌐 **Live Demo:** [https://shrishailamaganoor-creator.github.io/cyclesquad/](https://shrishailamaganoor-creator.github.io/cyclesquad/)

---

## 🌟 Highlights & Features

- **🎮 Open-World Exploration:** Seamless retro top-down pixel-art world with day/night atmospheric effects, procedural eco-zones, towns, and secret paths.
- **♻️ Waste-Sorting Arcade:** Categorize plastics, organic matter, hazardous e-waste, glass, paper, and metal with real-time scoring and combo multipliers.
- **🗺️ Interactive Recycling Map:** Search nearby drop-off and recycling centers with embedded live map finders.
- **📜 Quests & Progression:** Complete NPC quests, level up your Eco-Rank, unlock bike upgrades, badges, and sustainability achievements.
- **🔊 8-Bit Retro Synthesizer:** Fully procedural Web Audio sound effects and chiptune soundscapes with no external sound assets required.
- **📱 Fully Responsive:** Play seamlessly on desktop with keyboard controls or on mobile with custom on-screen virtual d-pad controls.

---

## 🕹️ Controls

| Action | Desktop Keys | Mobile / Touch |
|---|---|---|
| **Move** | `Arrow Keys` or `W`, `A`, `S`, `D` | On-Screen D-Pad / Joystick |
| **Interact / Talk** | `Space` or `E` | Action Button (`A`) |
| **Dash / Sprint** | Hold `Shift` | Dash Button (`B`) |
| **Inventory / Menu** | `Esc` or `M` | Menu Icon |

## 🚀 Running Locally

No build tools, npm packages, or server runtimes required! CycleSquad is 100% self-contained:

1. Clone the repository:
   ```bash
   git clone https://github.com/shrishailamaganoor-creator/cyclesquad.git
   ```
2. Open `index.html` directly in any modern web browser (Chrome, Edge, Firefox, Safari).
